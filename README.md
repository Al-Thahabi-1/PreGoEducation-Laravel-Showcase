## PREGO Education – Laravel Showcase

This repository is a **showcase** for a Laravel-based educational consultancy website
that helps students in Turkey plan their university studies in Italy.

The original project was built for a real client and remains private.
This public repository focuses on presenting the project structure,
features, and development approach.

### Project Overview
- Educational consultancy platform
- Italian universities directory
- Informational pages, blog, and news content
- Clean and responsive user interface

### Key Features
- University listings with details and locations
- Blog and news system
- Multi-page website structure
- Multilingual-ready architecture (TR / EN)
- Structured layout using Blade templates

### Tech Stack
- PHP (Laravel)
- MySQL / MariaDB
- Blade templating engine
- Bootstrap 5
- Vite for asset bundling

### My Role
- Project setup and architecture
- Backend logic and routing
- Page implementation using Blade
- Frontend integration and styling
- Overall project integration

### Notes
- Client-specific data and credentials are excluded
- This repository is for **portfolio and demonstration purposes only**
